# A/C source and asset rights

The owner approved publication of these original Nullworx studies on 2026-11-14.
Original integration, optical shader, SDF, procedural light rig and ribbon geometry
ship under the repository MIT license. No reference composition, photography,
video, proprietary source, GSAP code or rejected experiment is copied.

Installed LICENSE files were inspected for `three@0.187.0` and `three-text@0.6.5`;
both grant MIT permission. The three-text runtime closure includes HarfBuzzJS
0.4.15 (MIT with retained component notices), libtess-ts 0.0.1 (SGI-B-2.0), woff-lib
0.0.3 and brotli-lib 0.0.7 (MIT plus component notices). Full supplied notices are
preserved in `components/visual-frontier/THIRD_PARTY_NOTICES.md` and consumer
source. Optional hyphenation language patterns are not imported or offered as assets.

A's exact Space Grotesk Bold WOFF and HarfBuzz WASM bytes are encoded as portable
TypeScript constants. `asset-manifest.json` pins decoded SHA256 and byte counts.
Space Grotesk 5.2.10 is SIL OFL 1.1; full terms are retained in
`OFL-SpaceGrotesk.txt` and the notices. Font and SGI components are not relicensed
as MIT. Encoding does not alter their terms.

C1 retains the original Shader Park 0.2.8 sculpt and exact locally compiled GLSL.
The installed compiler LICENSE grants MIT permission; its package metadata says
Apache-2.0. This inconsistency is recorded and the shipped MIT grant is reproduced
for the generated GLSL boilerplate. Shader Park and its older Three dependency
are not runtime dependencies. Consumers do not run a compiler or arbitrary code.

OGL is removed by retaining A's optical formulas in the same Three context; its
lab metadata/notice inconsistency does not enter distribution. No brush or painting
renderer is installed. No public/ asset or release allowlist exception is needed.
The separately provisioned homepage fish media contract remains unchanged.

Historical references remain in the untouched lab's `evidence/reference-inspection.json`
and `reference-pins.json`: external compositions were studied for techniques only;
their finished UI and media are excluded.
