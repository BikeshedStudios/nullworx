# Distribution verification

Run `pnpm test:distribution` after installing root dependencies and Chromium. It runs the registry negative tests and creates disposable consumers outside the source tree. Fixture code/config uses `.template` to keep it out of the site's TypeScript/lint graph. The manifests, independent lockfiles and minimal shadcn configurations are committed. Vite's pnpm workspace lists the exact dependency release-age exceptions generated during lock creation; no unpinned dependency is added to the site.

`consumers.mjs` validates the public GitHub registry with shadcn 4.23.0, verifies dry-run has no writes, installs both consumers from `BikeshedStudios/nullworx/magnetic-focus#4cd0e4b6f8efc95dfd2e4fd2e641c7d194ac378e`, checks exact source bytes and unchanged consumer configuration, builds both projects, and runs `interactions.mjs` in Chromium. The fixture stylesheet deliberately supplies no global box-sizing reset. Registry, component sources and license are fetched from public GitHub. No source file is manually copied into the consumers; no local transport or fallback exists. Override `NULLWORX_PUBLIC_REGISTRY_SHA` with another full public SHA when deliberately testing a later release.

`pnpm test:distribution:site` runs a separate production-site matrix after `pnpm build`: home, gallery, eight effect routes × desktop/390/320px × normal/reduced motion. It scans all ten pages with axe and writes exact findings. Expected 404s under `/media/local/` are recorded separately; other HTTP errors, console errors and page exceptions fail the test. This clean-media suite requires an unprovisioned checkout. Integration fixes the reproduced contrast findings without suppressing the gate; `pnpm test:launch` additionally checks Digital Wake's expanded controls and keyboard focus.

Ports default to 3440/3441 (consumers) and 3460 (site). Override `CONSUMER_PORT` or `DISTRIBUTION_SITE_PORT` for concurrent runs. No server reuse, pushes, deployments, or background workers. Logs and screenshots are retained under the printed OS-temporary directory. See the install document for the verified public source and version limits.
